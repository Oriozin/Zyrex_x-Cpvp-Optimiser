# Zyrex_x Cpvp Optimiser

This is a Fabric client-side testing mod for Minecraft 1.21.1.

Features:
- HUD for crystal / anchor / pearl catch status
- Crystal Speed slider values from 1x to 4x
- Anchor Speed slider values from 1x to 4x
- Toggle HUD with H key
- Config file saved to `.minecraft/config/zyrex_cpvp_optimiser.json`

Important:
- This is designed for local testing and custom client-side experimentation.
- Use only in environments where you have permission.

## Build

```bash
./gradlew build
```

## Install

After building, copy the generated JAR from:

`build/libs/zyrex_cpvp_optimiser-1.0.0.jar`

into your Fabric mods folder.
